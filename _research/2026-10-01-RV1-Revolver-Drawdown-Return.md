**Run:** 2026-09-27, Europe/Berlin, by grok (Cursor web search). Brief: `Parcel_RV1_Revolver_Drawdown_For_Grok_Cursor.md`.
**Scope kept:** this return file and the grok handover row only; nothing else in the repo edited. Filename kept as the brief names it.
**Page convention:** "p. N" is the PDF page index of the exact file opened (NBER, FRBSF and Fed PDFs), not the printed page
number. Where the free version is a working paper, the published version was checked for existence only (paywalled).
**Grades** as defined in `CHARTER.md` "Grades": MEASURED (observed on a stated universe and denominator), BOUNDED (one-sided),
HYPOTHESIS (untested, or tested and still standing). A rate I derived myself from a source's own table is marked "derived".
**Out of scope, respected:** no precedent rate is applied to any current exposure; no description of any industry
classification as lending to a build-out (C-115); no price or stock-return claims (C-077); no paid data pulled.
